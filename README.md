# Document Tracker

Simple static web project for tracking documents.

Files

- `index.html` — main page
- `app.js` — frontend logic
- `app.css` — styles
- `mockData.js` — sample data

Usage

1. Open `index.html` in a browser (double-click or serve with a static server).
2. For development, run a simple static server (e.g., `npx http-server` or `python -m http.server`).
